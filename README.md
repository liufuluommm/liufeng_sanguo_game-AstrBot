- AstrBot 版本要求：`>=4.17.0`
- 支持平台：`aiocqhttp`（OneBot v11 / QQ 个人号）、`qq_official`（QQ 官方机器人）

## 一、简介与核心循环

一款接入 QQ 群的三国题材**卡牌收集 / 养成 / 对战**游戏插件，内置完整经济、经营、社交与运营体系，并提供 WebUI 管理台与 GM 工具。

核心循环：**招募武将 → 养成变强 → 挑战副本 / 群友对战 → 收集更多武将**。

## 四、玩法系统详解

### 1. 账号与基础
- `/注册` 建立档案；`/签到` 每日签到领取金币；`/帮助` 指令总览。
- **维护模式**：开启后所有指令被 `_guard` 拦截并提示原因（GM 指令与仪表盘可开关）。
- **封禁**：管理台可封禁玩家，被封禁者发送指令时被拦截。

### 2. 武将体系
- **规模**：历史 150 / 冷门 100 / 架空 120，共 **370** 名。
- **多维能力（六维）**：武力 → 攻击、体力 → 生命、速度 → 先手、智力 → 防御/暴击、魅力 → 团队光环、口才 → 削弱敌方；六维**计入战力**。
- **品质**：超稀有(SSR)/史诗(SR)/稀有(R)/普通(N)；**势力**：魏/蜀/吴/群。
- **称号**、**羁绊**（同队达到条件触发全队加成）。
- 查看：`/武将 [名]`、`/图鉴`。

### 3. 招募与宿舍
- **碎片兑换**：`/碎片` 查看通用碎片；`/兑换` 消耗碎片随机兑换历史/冷门武将（重复自动升星）。
- **架空招募**：`/架空招募`（金币，有失败率）、`/架空十连`。
- **自由武将**：无前缀 `自由武将招募 <名字>`，随机六维 + **随机基础兵种**，占用宿舍名额。
- **宿舍**：`/宿舍` 查看、`/宿舍升级` 扩建名额。

### 4. 养成
- **升级**：`/培养 <武将> [次数]`（金币提升等级）。
- **升星**：`/升星 <武将>`（提升星级系数）。
- **技能**：见「技能系统」。
- **图鉴**：`/图鉴` 收集进度。
- **合成**：`/合成 n|r|sr` 消耗 3 名同稀有度（未上阵）合成更高稀有度。
- **遣散**：`/遣散 <武将>` 返还资源。

### 5. 技能系统
- **技能槽（王者式）**：每将 **被动 1 + 主动 1/2/3**。
- **效果原子**：伤害（兵刃/谋略/真实）、治疗/回复、增益/减益、持续伤害、控制、护盾、净化、驱散、无敌、不可选中、回复、斩杀、复活等；每个效果可设**概率随机抽取**。
- **效果库**：`tables/skill_effects.json` **350 个**模板；按技能名**确定性**生成。
- **技能书 + 技能书碎片**：`/技能店` 浏览、`/兑换技能书 <技能名>` 兑换、`/学技能 <武将> <技能名>` 学习/更换（旧技能不返还、等级重置，可配置）；碎片可 `/商店 兑换 ex_gold_skillfrag` 以金币兑换。
- **内置 30 技能** `tables/builtin_skills.json`。
- **管理台「技能工坊」**：可视化增删改，配置伤害公式（双防穿透/缩放/法力）、效果原子；保存自动生成技能书。
- 指令：`/技能 <武将> [槽 1|2|3|passive]` 按槽升级。

### 6. 兵种系统
- **分级（16 种）**：
  - 基础：步兵 / 骑兵 / 弓兵 / 枪兵
  - 精锐：重步兵 / 铁骑 / 强弩兵 / 长枪兵
  - 特殊：虎豹骑 / 白毦兵 / 陷阵营 / 锦帆军 / 无当飞军 / 藤甲兵 / 象兵 / 白马义从
- **克制关系** + **携带效果**：属性加成（攻/防/血/速/暴击/免伤…）、特殊机制（受谋略易伤、追加一击、击飞、先手、背水）、开局效果（护盾/增益/回复）。
- **兵种效果库**：`tables/troop_effects.json` **100 个**（名字随机化/架空化）。
- **管理台「兵种库」「兵种效果库」**：内置只读，可新建自定义兵种/效果并**自由设置数值**（开局效果已中文化）。
- 兵种来源：历史武将按史实、架空随机、自由武将随机基础兵种；管理员可改任意武将兵种。

### 7. 战斗系统
- **模式**：PvP **1v1**（`/对战`）、切磋（`/切磋`）、PVE 3v3（副本）。
- **公式**：`伤害 = (基础值 + 属性×系数) × (1 − 防御减免) × (1 − 免伤)`，减免 `= 防御/(防御+120)`，真实伤害无视防御；含**固定/百分比穿透**。
- **属性**：暴击/暴伤/攻速/冷却缩减(CDR)/韧性/免伤/吸血/法术吸血/**法力**。
- **克制**：兵种克制倍率；**羁绊**加成；**竞技评分**（PvP）。
- **技能释放**：被动开局生效，主动按概率/冷却/法力释放。

### 8. 阵容与主将
- `/阵容` 查看；`/上阵 <武将>`、`/下阵 <武将>`；`/主将 <武将>` 设定 1v1 出战主将。

### 9. 装备系统
- **部位**：武器 / 防具 / 坐骑 / 宝物；**品质** SSR/SR/R/N；三维加成（武/智/统）。
- `/装备` 查看、`/锻造`（金币随机）、`/强化 <序号>`、`/穿戴 <序号> <武将>`、`/卸下 <武将> <部位>`。

### 10. 副本 PVE
- 六章 24 关：黄巾之乱 → 虎牢关 → 官渡 → 赤壁 → 夷陵 → 五丈原。
- 消耗**行动力**，掉落**通用碎片**与金币；`/副本` 总览、`/挑战 <关卡>`、`/扫荡 <关卡>`。

### 11. 道具与背包
- **效果引擎（schema 驱动）**：金币/碎片/货币/体力、开箱、自选礼包、限时 buff、学习技能等。
- `/背包` 查看、`/使用 <道具> [数量]`、`/选择 <礼盒> <选项>`（自选礼包）。

### 12. 经济经营
- **商城**：`/商城` 总览；`商店 每日/每周/黑市/活动`；`商店 购买 <条目>`；`商店 锁定/解锁`。
- **兑换所**：`商店 兑换所 [分类]`、`商店 兑换 <目标ID> [数量]`（单向，含金币 → 技能书碎片）。
- **拍卖行**：一口价 + 竞拍（保证金 + 抽税）；`拍卖 查看/我的/上架装备/上架碎片/出价/一口价/下架`。

### 13. 社交
- **势力国战**：`/势力`、`/加入 <势力>`、`/捐献 <数量>`、`/势力战`。
- **军团（公会）**：`/军团`、`/创建军团 <名字>`、`/加入军团 <ID>`、`/退出军团`、`/军团捐献 <金币>`、`/军团排行`。
- **好友**：`/好友`、`/加好友 <QQ>`、`/赠体力 <QQ>`。
- **切磋**：`/切磋 <对手>`。

### 14. 运营
- **任务 / 成就**：`/任务`、`/成就`、`/领取`。
- **邮件**：`/邮件`、`/领邮件 [编号]`（奖励走附件）。
- **战令（通行证）**：`/战令`、`/战令领取`、`/战令购买`。
- **限时活动**：`/活动`（四类全局 buff：掉落/金币/经验翻倍、免行动力）。
- **世界BOSS**：`/世界boss`、`/讨伐`（全服共战、伤害排行、邮件发奖）。
- **定时推送**：系统定时向订阅会话推送。

### 15. 展示
- `/卡牌 <武将>` 文转图武将卡（无 Playwright 时自动回退纯文本）。

## 六、管理台（WebUI）

插件详情页打开「三国管理台」（全中文），仅管理员可用（`admin.web_admins` 白名单）。共 **14 个页面**：

| 页面 | 功能 |
|---|---|
| 仪表盘 | 多维实时指标（注册玩家/今日签到/累计金币/自定义武将/武将·兵种·技能·道具·装备数/军团/拍卖/活跃活动/定时任务）+ 世界BOSS 与维护状态 + **维护模式一键开关** |
| 玩家管理 | 搜索/封禁标记；资料修改、货币与资源、邮件发放、武将/道具增删、批量清空、封禁/解封、**删除玩家（连带清理）** |
| 武将库 | 搜索/筛选/分页；自定义武将新增·编辑·删除（六维） |
| 技能工坊 | 技能增删改 + 公式/效果原子可视化编辑，自动生成技能书 |
| 兵种库 | 内置只读；新建自定义兵种、自由设置携带效果 |
| 兵种效果库 | 内置 100 效果（架空名）；新建自定义效果 |
| 道具工坊 | 道具增删改，类别/品质/货币/效果全部下拉 |
| **军团管理** | 军团列表/详情；改名、等级资金经验、解散、踢人、转让军团长 |
| **装备管理** | 装备库（蓝图）CRUD + 玩家装备发放/强化/移除/卸下 |
| **拍卖行** | 挂单列表；强制下架/结算/删除、一键结算 |
| **活动管理** | 活动定义 CRUD、开启/关闭、全局启用开关 |
| **定时任务** | 任务状态（**中文名**）；立即执行、改间隔、暂停/恢复；**自定义定时任务**（12 动作目录、中文参数、固定间隔、持久化热重载） |
| **世界BOSS** | 状态与排行；开启（选BOSS+时长）、提前结算、强制关闭；定义 CRUD |
| 广播推送 | **群聊广播**（目标可选：群聊/私聊/全部，默认群聊，仅已记录会话）；会话预览；回显 成功/失败/跳过。**当前默认已临时禁用**（配置 `system.enable_broadcast`，默认关闭，可开启恢复） |

## 八、数据存储规范

- **按 QQ 号分文件**：`.../players/<QQ>/player.json`（+ `mail.json` 等子数据）。
- **跨群全局数据**：`.../global/*.json`（排行榜、势力、军团、拍卖、世界BOSS、活动状态、战令、会话索引、审计、维护状态、封禁名单等）。
- **原子写入**：临时文件 + `os.replace`，进程内加锁。
- **自定义数据（不随插件更新丢失）**：`items_custom.json`、`skills_custom.json`、`generals_custom.json`、`troops_custom.json`、`troop_effects_custom.json`、`equipments_custom.json`、`events_custom.json`、`bosses_custom.json`、`custom_jobs.json`。
- **数据目录**：优先 `get_astrbot_data_path()/plugin_data/<name>`，开发环境回退 `local_data/`。

## 九、配置项（`_conf_schema.json`）

- `enable`：总开关。
- `game`：初始金币、签到/对战奖励、战斗波动。
- `gacha`：碎片兑换数、稀有度概率、架空招募花费与失败区间、自定义招募花费与区间、宿舍参数。
- `dungeon`：碎片掉率区间。
- `stamina`：行动力上限与恢复。
- `text_image`：文转图开关与主题。
- `system`：调度器、主动推送、**广播推送开关（`enable_broadcast`，默认关闭）**、维护模式、冷却、屏蔽平台。
- `admin`：超管 QQ 列表、管理台用户名白名单。
- `worldboss` / `battlepass` / `events`：对应系统开关与参数。
- `skill`：技能系统开关、默认技能书碎片价、是否返还技能书、是否重置等级。

## 十、安装与部署

1. 将 `liufeng_sanguo_game/` 放入 `AstrBot/data/plugins/` 下。
2. 在 AstrBot WebUI 插件页刷新/重载插件。
3. 接入 QQ（QQ Official Bot WebSocket 或 OneBot v11）。
4. 群内发送 `/注册` 开始游戏。
5. 管理台：插件详情页 →「三国管理台」。

## 十一、运行环境与依赖

- Python 3.10+（开发环境 3.11）。
- AstrBot `>=4.17.0`。
- `requirements.txt`：`aiofiles>=23.0.0`。
- 文转图依赖 AstrBot 的 Playwright 渲染能力；不可用时自动回退纯文本。

## 十二、已知限制

- QQ 官方接口**不支持 At 消息段**：`@` 类指令需改用 QQ 号；且**不支持主动消息**，定时推送/广播自动跳过该类会话。
- 定时任务需 AstrBot 运行事件循环；调度器在 `on_astrbot_loaded` 钩子中启动。
- GM 权限基于 AstrBot 管理员 + 插件超管白名单，建议上线前实测。
- 技能效果 `combo/pursuit/counter/summon` 部分为占位（未实现完整战斗逻辑）。
